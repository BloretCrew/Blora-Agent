# Security

Blora Agent executes model-requested work against a local workspace. Default policy is fail-closed.

## Report

Do not file public issues for unreleased tool execution or sandbox bypasses. Contact the maintainers privately.

## Current scope

This release only persists events and runs a mock model. It does not execute shell commands or write project files yet. When tools land, destructive Git, unrestricted network, and path escape will require explicit approval.
