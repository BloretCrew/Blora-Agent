# TUI 快捷键

界面是一块留白的对话画布：顶栏只写 `blora · mode · 会话`，消息用左侧色条区分你 / 助手，底栏是 `❯` 输入、一行状态、一行快捷键。没有围满全屏的边框。

## 自适应侧栏

终端至少 **100 列 × 18 行**时显示左侧导航栏（默认 **28 列**，含分隔线）；低于任一阈值时隐藏侧栏、画布恢复全宽。按住左右侧栏与对话区之间的分隔线拖动，即可调整对应侧栏宽度，拖动范围会为对话区保留至少 40 列。点击左栏顶部的 `‹` 折叠左栏，点击折叠后左侧的 `›` 展开；右栏沿用顶部的折叠/展开按钮。折叠后展开会恢复本次运行中选择的宽度。缩放不重置当前会话、输入草稿或消息滚动位置，原有顶栏、快捷键和斜杠命令始终保留。

侧栏顶部显示 Blora 品牌、新建会话及搜索会话入口，复用已有新建逻辑与会话搜索窗口。「项目」按工作区路径去重，点击项目切换到该项目已有会话；点击分区标题打开项目选择窗口。「最近会话」沿用已有数据顺序，只显示当前项目的会话，当前项高亮；空标题显示「未命名会话」，长中文或英文按终端显示列宽截断。底部提供设置窗口入口及当前用户名称，未登录时显示相应状态。

鼠标滚轮只滚动指针所在的项目或最近会话列表，不影响对话消息；侧栏其他位置的滚轮不会滚动消息。切换会话后自动保持当前项可见，随后仍可手动滚动浏览其他会话，不会每帧跳回当前项。对话区域继续使用原有消息滚动与文本选择。窗口较矮时缩减项目列表，优先保留操作入口、会话列表与底部入口。

弹窗仍按**完整终端**居中并调暗整个背景（包括侧栏），复用窗口栈与关闭动画；打开、最小化及关闭动画期间，侧栏点击和滚轮不会穿透到后台。

输入 `/` 后，prompt 上方弹出命令列表（名称、参数提示、说明）。边打边过滤（前缀 / 子串 / 子序列），`Tab` 补全，`↑` `↓` 选择，`Enter` 执行。需要参数的命令（提示以 `<` 开头）在补全后停在 `/name `，补完参数再回车。`Esc` 先关补全或结果面板，再退出。`Ctrl+P` 在空 prompt 上打开 `/` 菜单。`NO_COLOR` 时退回终端原色。

| 键 | 作用 |
|---|---|
| Enter | 发送当前输入；以 `/` 开头则补全或执行选中的斜杠命令；运行中则作为插话排队，下一轮送达 |
| Tab | 补全选中的斜杠命令 |
| ↑ / ↓ | 浏览本次启动期间已发送的输入历史；↓ 回到最新位置时恢复草稿。斜杠菜单与弹窗中用于选择项目 |
| Ctrl+P | 打开斜杠菜单（prompt 为空时） |
| Esc | 关闭斜杠菜单或结果面板；否则退出 |
| Backspace | 删除输入 |
| `[` / Left | 上一个会话（输入为空时） |
| `]` / Right | 下一个会话（输入为空时） |
| PageUp / PageDown | 滚动 transcript |
| Home / End | 滚到最早 / 最新 |
| y / n | 批准或拒绝当前审批（输入为空时） |
| Ctrl+N | 新建会话 |
| Ctrl+C | 请求取消并退出 |
| 滚轮 | 滚动 transcript；在斜杠列表上则移动选中项 |
| 单击 | 执行斜杠命令、审批、切换会话、底栏动作 |

鼠标（终端需支持 SGR 鼠标）：滚轮滚动对话；斜杠列表悬停高亮、单击执行（需要参数则补全）；点 `y allow` / `n deny` 审批；顶栏 `‹ ›` 切换会话；点 `running` 取消当前 run；点当前权限名称（如 `default` / `bypassPermissions`）打开独立权限模式选择器；底栏快捷键可点。点斜杠菜单或结果面板以外的区域会关闭它们。

`/help`、`/git`、`/files` 等较长输出显示在 prompt 上方的结果面板，`Esc` 或点击关闭。

## 执行内核（Harness）

单击左上角当前内核名称（默认 `Blora`），或输入 `/harness` 打开执行内核选择窗口。提供 Blora、Claude Code、Codex、Grok Build、Hermes Agent、OpenClaw、OpenCode、Qwen Code、DeepSeek Harness 共九项；每次打开根据 PATH 刷新安装状态，不以参考源码目录判断，也不会自动安装或验证登录。未安装项灰色显示，点击或 Enter 均不能启用。

外部 CLI 需先按各项目的官方说明安装并完成登录，以下为 PATH 中检测的可执行命令，不是自动安装指令：

| 内核 | CLI 命令 |
|---|---|
| Claude Code | `claude` |
| Codex | `codex` |
| Grok Build | `grok` |
| Hermes Agent | `hermes` |
| OpenClaw | `openclaw` |
| OpenCode | `opencode` |
| Qwen Code | `qwen` |
| DeepSeek Harness | `dsh` |

使用 ↑/↓ 选择、Enter 确认、Esc 关闭；单击可用项立即确认。窗口复用共享栈、动画和红/黄/绿关闭、最小化、全屏控件，最小化后 Enter 只恢复，键盘和粘贴不会穿透后台。24×10 等窄屏仍保留左上入口，长名称截断，全部九项均可用方向键访问，超出可见高度时选项随选择滚动；也可随时用 `/harness` 从主界面打开。

选择保存在当前 Blora 会话，切换会话和重启恢复。前台运行期间不能切换，必须先取消或等待完成。键盘和鼠标发送使用同一路由；外部运行中输入与 `/steer` 只排队，在当前请求结束后送达，不表示即时插话成功。

外部 CLI 使用自身登录、模型、配置、规则、插件与权限/沙盒，绕过 Blora 的 PassPort 登录检查；Blora 原生模型、供应商设置不会改变外部 CLI。底栏显示外部内核与 CLI 返回的实际模型（未知时为 `—`），并明确标注 CLI 自身模型/权限。供应商/模型窗口和设置页标注「Blora 原生设置」。安装并不意味着已经登录，登录或协议错误会作为运行失败显示，绝不静默切回 Blora。

权限选择仅映射到 CLI 支持的能力，不支持的组合由运行层拒绝；Blora 原生网络、路径及沙盒约束不覆盖外部 CLI。跳过确认仍需显式风险确认。仅前台会话请求走外部内核；后台任务、Git 辅助生成和 Imagine 保持 Blora 原生边界，外部内核与 Imagine 的不支持组合会被拒绝。本次不改变 Web 路由。

| 内核 | 默认确认 | 自动接受编辑 | 计划 | 跳过权限确认 |
|---|---|---|---|---|
| Claude Code | `dontAsk`，拒绝未预批准操作 | `acceptEdits`，需要额外确认的操作由 CLI 拒绝 | 暂不支持可靠只读约束 | 显式 `bypassPermissions` |
| Codex | 只读沙盒，审批策略 `never` | 暂无安全等价映射 | 只读沙盒，审批策略 `never` | 显式绕过审批及沙盒 |
| Grok Build | `default`，无头接口拒绝无法审批的操作 | `acceptEdits` | 暂不支持已验证的只读沙盒映射 | 显式 `bypassPermissions` |

新增内核的权限能力取决于对应 CLI 的已验证无头协议；不保证与 Blora 四种权限模式逐项等价，不支持或无法保证的组合会被拒绝。

| Hermes Agent | 暂不支持 | 暂不支持 | 暂不支持 | oneshot 模式，仅最终文本 |
| OpenClaw | 暂不支持 | 暂不支持 | 暂不支持 | 本地请求，核对已配置工作区后执行 |
| OpenCode | 无头请求拒绝需要确认的操作 | 暂不支持 | 暂不支持 | `--auto`，仍遵循外部拒绝规则 |
| Qwen Code | `default` | `auto-edit` | 暂不支持可靠只读约束 | `yolo` |
| DeepSeek Harness | 暂不支持 | 暂不支持 | 暂不支持 | headless profile 自身权限，仅最终文本 |

Hermes 和当前安装版本的 DeepSeek 每次发起独立请求，由 Blora 补充历史；这两个接口不提供工具活动、思考、用量或可绑定会话 ID。OpenClaw 使用 `--local --json` 最终响应、显式 UUID 及 Blora 会话命名空间；启动前要求其默认 agent 的已配置工作区与当前项目相同。工作区不匹配、JSON5 配置、配置 includes 或环境插值会明确拒绝，用户可通过 OpenClaw 自身配置调整。Blora 只读核对配置，不修改外部配置。OpenClaw 自动频道投递关闭，模型调用的外部工具仍可能联网或发送消息，需明确风险授权。

外部 CLI 自身已有的允许/拒绝规则仍适用，单向无头接口目前不提供 Blora 内的逐工具交互审批。外部执行当前支持 Unix 平台；取消清理同进程组的后代，主动脱离进程组的进程需要另行管理。每条输入最多 32 KiB，跨内核历史同步保留最多 64 KiB 的 UTF-8 安全尾部，并标注省略；同一外部会话的连续请求使用明确会话 ID 续接。

## 权限模式选择器

点击底栏当前权限名称打开「权限模式」窗口，使用 `↑` / `↓` 选择，`Enter` 确认，`Esc` 取消；鼠标单击可见普通选项立即确认，悬停或窗口内滚轮只移动选择。选项旁标记「当前」，未确认前不会改变权限。

| 模式 | 说明 |
|---|---|
| `plan` | 只读探索；仅允许写入 `.blora/plan.md`，禁止修改性 shell 命令 |
| `default` | 文件写入和修改性 shell 命令需要确认 |
| `acceptEdits` | 工作区文件编辑免确认；修改性 shell 命令仍需确认 |
| `bypassPermissions` | 跳过普通及危险操作审批；硬性网络禁用、工作区边界与沙盒限制仍有效 |

主界面 `Shift+Tab` 按 `default → acceptEdits → plan → default` 循环，不进入 `bypassPermissions`；从绕过模式切换则回到 `default`。选择 `bypassPermissions` 或使用 `/yes on`、`/settings auto-approve=on`、`/settings permission=bypassPermissions` 时，必须先阅读风险提示并按 `y` 明确确认；`Enter` 和重复鼠标点击不会确认，`n` / `Esc` 取消且保留原模式。

此窗口复用共享窗口栈、亮度动画和红/黄/绿标题栏控件，支持关闭、最小化、展开；最小化后 `Enter` 只恢复，不确认。窄屏使用紧凑单行选项，说明显示在下方，选择会自动保持可见。弹窗输入不会穿透后台。

当前权限以完整模式传给后续前台运行（包括键盘/鼠标发送及插话后续运行），Git 提交说明生成的 RunOptions 也携带当前模式。切换不会改变已经启动的运行；此权限不是会话工作模式，`/plan` 仍用于切换工作模式。Git 手动提交/同步等显式 UI 操作不是模型工具审批。

兼容入口 `/yes` 保留自动批准开关的切换语义（`/yes on` 为 `bypassPermissions`，`/yes off` 为 `default`），`/no` 设置 `default`；设置中的「权限模式」在三个普通模式间循环； `/settings auto-approve=on/off` 兼容开关映射为 `bypassPermissions` / `default`，不会留下另一份独立布尔状态。`/permissions` 显示完整当前模式。权限选择仅对当前 TUI 进程有效，重启默认为 `default`。

后台 `/task`、`/cron`、`/loop` 保留已有任务语义：只保存自动批准布尔开关，`bypassPermissions` 对应开启，其他模式对应关闭，不保存或继承 `plan` / `acceptEdits`。排队成功状态会明确显示这一差异；`/pump` 仍按任务中已保存的设置运行，不使用之后切换的前台权限。

## 手机与窄屏终端

通过手机终端或 SSH 使用时，界面会根据终端列数和行数自动调整，无需开启额外选项：

- 小于 60 列时减少左右留白，底栏使用紧凑中文操作按钮；支持 SGR 鼠标的终端可以直接点按。
- 模型信息优先显示 当前权限模式名称（`plan` / `default` / `acceptEdits` / `bypassPermissions`），长模型名按可用宽度省略，点击可见模型名称打开选择器。
- 供应商与模型窗口在内容宽度不足 60 列时改为上下排列，方向键和点按保留原有行为，选中项自动保持可见。
- 少于 14 行时省去顶栏分隔行；软键盘打开或终端缩小时，命令菜单缩短，并保留输入区与对话空间。
- 长中文输入显示完整字符的末尾，并为输入光标保留一列。

窄屏终端中，主画布顶栏两端分别提供左右抽屉入口。抽屉覆盖主画布并渐暗背景，同一时间只打开一侧；点击遮罩、抽屉关闭入口或按 Esc 关闭。抽屉采用约 280ms 的缓动滑入/滑出，动画期间后台点击不会触发。会话导航沿用侧栏列表、项目、搜索和设置入口；右侧抽屉沿用信息、文件、终端与侧聊标签。手机终端需要自行支持触摸到 SGR 鼠标事件的转换；也可用键盘操作。

## 弹窗与窗口栈

弹窗按打开或重新激活的先后顺序叠放，最后激活的窗口位于最上层；同一个窗口不会在栈中重复出现。键盘、鼠标点击、悬停和滚轮只操作最上层窗口，点击窗口外部不会触发后面的窗口、会话切换、审批或输入框。

红色标题栏控件只关闭最上层窗口，黄色控件将它最小化为标题栏，绿色控件切换全屏；最小化时绿色控件或 `Enter` 恢复窗口。最小化的窗口仍是模态窗口，不会让输入穿透。关闭子窗口后恢复父窗口及其选择、滚动等状态，例如供应商的新增向导、项目选择器的文件夹浏览器，以及设置中打开的引导。主题窗口关闭时撤销未保存的主题预览。

弹窗打开时，`Ctrl+N`、`Ctrl+P`、输入历史、斜杠补全、会话切换和审批快捷键不会操作后台。`Ctrl+C` / `Ctrl+Q` 仍可取消并退出。终端粘贴、`Ctrl+V` 和 `Insert` 只写入栈顶可编辑字段：新增供应商的搜索、标识、地址和密钥，或正在编辑的 Git 提交说明；其他弹窗及最小化窗口忽略粘贴，不改变后台草稿。

弹窗留在后台时，其数据和异步任务仍继续更新，例如 Git 差异读取、提交说明生成、同步以及账号授权；异步更新不会自动把后台窗口提到前台。

窗口打开和关闭使用 180 毫秒的 smoothstep 亮度动画，仅动画活动时以约 30 帧/秒刷新。标题、边框和内容从低对比度渐变到正常亮度，关闭时反向变化；下方页面及父窗口按上方窗口的浮点可见权重之和同步调暗或恢复，并保留最低可辨认程度。最小化窗口仍计为一层，最小化和全屏布局即时切换。浅色、深色主题均适用，预览切换不会重启动画；连续重绘从原始窗口颜色合成，不会累积变暗。

开启动画期间窗口可交互；关闭操作立即执行一次取消、保存或主题回滚等业务动作，并释放业务状态，只保留已遮蔽敏感字段的窗口原始绘制层直到淡出完成。关闭画面仍阻止按键、鼠标、滚轮和粘贴穿透，`Ctrl+C` / `Ctrl+Q` 仍可退出。快速重新激活同一窗口从当前亮度反向继续，不产生重复视觉窗口。终端缩小时关闭画面安全裁剪；切换会话或项目时清理旧上下文的关闭残影。

## Git 文件选择与差异

Git 窗口默认打开“操作”页。单击文件行选中并查看差异，在同一文件行上 500 毫秒内双击切换勾选；`↑` / `↓` 选择文件，空格切换勾选。右侧显示所选文件的完整统一差异，涵盖已暂存和未暂存变更、新文件与删除文件；二进制文件显示 Git 的差异说明。

鼠标停在差异栏上滚动，或使用 `PageUp` / `PageDown` 浏览差异；文件列表与差异各自保留滚动位置。切换文件会重置差异位置。较窄且高度足够的终端使用上下布局，极小窗口可点击绿色控件展开。

## 首次使用引导

首次启动进入欢迎、账号、完成三个步骤。`Tab` / 方向键选择操作，`Enter` 确认，鼠标可直接点击操作行。点击登录后显示设备码与授权地址，可打开浏览器、复制或取消。`Esc` 先取消正在进行的登录，再关闭引导；`Ctrl+C` / `Ctrl+Q` 退出程序。小终端会保留当前选中的操作，方向键可查看其他选项。

常规尺寸使用与设置、供应商窗口相同的圆角边框、标题栏和主题色。标题栏红色控件关闭引导，黄色控件最小化，绿色控件切换展开；最小化后按 `Enter` 恢复。欢迎页说明工作模式，账号页集中显示授权信息，完成页列出账号和配置保留情况。`PageUp` / `PageDown` 可滚动说明和较长授权地址；小终端使用紧凑布局。

选择“稍后设置”保留已有供应商配置，点击“开始使用”保存引导版本。`/login` 打开账号步骤，`/onboarding` 重开完整引导；关闭引导后保留原会话和输入状态。

## 消息角色标记

在 `/settings` →「外观」中选择「消息角色标记」，按 ←/→ 或点击该项切换。默认开启；关闭后隐藏用户与助手消息上方的名字和左侧彩色竖线，保留正文、Markdown、消息间距和工具摘要。设置立即生效，并保存在当前 Blora 数据库中，重启后继续使用。

也可以执行 `/settings message-roles=off` 关闭，或 `/settings message-roles=on` 恢复。

`/settings permission=default|acceptEdits|plan|bypassPermissions` 设置完整模式。CLI/API 支持旧别名 `ask`、`auto-edit`、`yolo`；CLI 显式 `--permission bypassPermissions` 或 `--yes` 视为非交互式风险授权，不另弹 TUI 确认。

### 权限名称与语言

权限选择器、底栏、设置项、模式切换反馈和风险提示使用同一套翻译资源。默认中文显示「默认确认」「自动接受编辑」「计划」「跳过权限确认」；设置 `BLORA_LOCALE=en` 后使用英文界面名称。内置中文与英文资源支持离线显示，远程翻译按键覆盖，缺失或空白译文保留内置回退。

命令、配置和事件仍使用 `default`、`acceptEdits`、`plan`、`bypassPermissions` 标识，旧别名继续兼容。

## 主界面提示

空会话显示欢迎引导：输入消息开始，使用 `/` 查找命令。宽屏同时显示产品说明、新建会话与输入历史快捷键；窄屏与低高度终端优先保留品牌和开始提示，文案按可用列宽省略。

输入框提示随状态变化：普通会话提示发送消息，Imagine 会话提示描述画面，运行中提示补充消息并按 Enter 排队发送。运行中底栏发送按钮同步显示「排队」，沿用现有排队行为。

状态栏空闲且无状态消息时显示当前项目目录名；根目录显示完整路径。状态消息按整行可用宽度显示。

## 会话窗口与搜索

点击顶栏会话名称打开会话窗口。顶部搜索框打开后即可输入，支持中文、退格和粘贴；下方使用双行列表显示会话标题、项目、最近更新时间和消息预览。

输入后立即筛选会话标题、ID 和项目名称，随后在后台分批搜索会话内容。「正在深入搜索会话内容…」显示搜索进度，内容命中项实时加入下方列表并显示匹配片段。搜索完成显示命中数量，搜索失败在窗口内显示错误。清空输入恢复全部会话。

使用 ↑／↓ 或滚轮跨结果选择，Enter 或单击打开目标会话，Esc 关闭窗口。窗口保留现有关闭、最小化和全屏控件；最小化期间输入保持隔离。快速改词与关闭窗口会使旧查询结果失效。

## 右侧工具栏

终端至少 **124 列 × 18 行**时显示右栏（36 列）；左栏仍沿用 100 列阈值与 28 列宽度，中间至少 60 列。尺寸不足时宽屏栏自动隐藏并保留各标签状态；不足 124 列或 18 行时可从主画布顶栏 `◧` 打开覆盖式右抽屉。宽屏点击右栏顶部 `›` 收起，主画布顶栏 `[◧]` 恢复。左栏导航不变。

默认「信息」页展示主会话标题、ID、项目、状态、内核、供应商/模型、权限与实际累计 token；无法确定的上下文用量显示未知，不用累计 token 冒充上下文。下方「文件」「终端」「侧边对话」按钮打开对应顶部标签，重复打开只激活已有标签。点击标签切换，`×` 或焦点内 `Ctrl+W` 关闭；信息标签不可关闭。

- **文件**随主会话项目更新。后台枚举最多 1000 项，预览最多 64 KiB，二进制、空文件、空目录及读取失败均有说明。目录/文件点击或方向键加 Enter 打开；顶部 `‹`、Backspace 返回；滚轮选择或滚动，预览 PageUp/PageDown 翻页。完整 UTF-8 文本可直接编辑，二进制、无效 UTF-8 和截断内容保持只读；不允许父目录或符号链接越出项目边界。
- **终端**首次打开在当时的项目启动真实交互 shell；内容顶部标明所属目录，切换主项目不会重绑已有 shell。标签隐藏或切换不结束进程，关闭标签及退出程序会清理。支持终端键盘、粘贴、ANSI 屏幕与缩放；`Ctrl+C` 发送中断，不退出 Blora。
- **侧边对话**创建独立且持久化的原生 Blora 会话，由 runtime 自动生成标题，标签和内容标题显示实际主题，保留独立 ID、创建项目与运行状态。创建时继承原生供应商/模型与权限配置，之后主侧独立维护，登录受阻保留待发送消息；Enter 发送，运行中消息进入自己的队列，`Ctrl+C` 取消侧聊并清空队列，不影响主会话。主/侧会话可并发、独立流式显示；审批条与提问窗口标记侧聊的真实标题。切换主项目不重绑侧会话；关闭时取消任务但不删除已保存历史，重新打开创建新会话。

点击右栏内容获得输入焦点；焦点行显示 `●`，`Ctrl+Tab` 切换右栏标签（非终端标签也支持 `Tab`；终端中的 `Tab` 用于 shell 补全），`Ctrl+G` 返回主输入，`Ctrl+Q` 始终退出。右栏因缩放隐藏时安全返回主输入。弹窗、最小化窗口和关闭动画隔离右栏键盘、粘贴、点击与滚轮。

### 右栏阅读与编辑

右栏标签共享可用列宽，当前页带底色与下划线，标签、关闭按钮、信息页操作及文件行支持悬停反馈。信息按会话、运行配置和累计用量分区；点击简写 ID 展开或收回完整值。外部内核标明配置和权限执行边界，未知上下文不等同累计 token。

文件顶部显示项目相对路径与刷新入口（`r`）。列表支持 Home/End、PageUp/PageDown；返回目录和预览后恢复选择。只读预览保留文件名与行号，↑/↓、PageUp/PageDown、Home/End 纵向浏览，←/→ 每次横移四列；底部显示当前位置与总行数。刷新重新读取文件，文件删除或读取失败不会继续显示旧内容。

终端滚轮向上以及 Shift+PageUp 查看历史，Shift+PageDown 向实时输出移动；历史位置显示于顶部，此时隐藏 shell 光标。End 或继续键入、粘贴返回实时输出；处于实时输出且 shell 启用鼠标协议时，滚轮交给 shell，按住 Shift 使用本地历史。退出或错误后点击顶部「重新启动」创建新 shell；运行中的 shell 不会被误重启。

侧聊直接复用主对话的转录缓存、消息布局和输入绘制代码：角色标记、Markdown、折叠工具摘要、思考内容和流式输出使用同一实现；`message_roles`、`hide_tools` 与 `/reasoning` 同时作用于主侧。工具摘要双击仅打开所属会话的工具详情，相同索引不会跨主侧命中。系统事件沿用主对话的展示规则。向上滚动查看旧内容，向下回到新内容；新输出到来时保留离底部的阅读锚点，已在底部则自动跟随。「到底部」显示新增渲染行数并恢复跟随。PageUp/PageDown 同样翻阅侧聊。主侧共享 UTF-8 编辑与输入历史组件，保留主窗口现有快捷键；侧聊草稿支持 UTF-8 安全的左右、Home/End、Delete/Backspace，↑/↓ 浏览最近 100 条已发送草稿并可返回未发送草稿；粘贴保留多行，Alt+Enter 或 Shift+Enter 换行，Enter 或「发送」排队。「取消」与 Ctrl+C 取消该侧聊并清空其队列。输入区自适应至五行并始终显示编辑光标，登录受阻保留队列供主窗口登录后重试。

### 文件编辑与语法高亮

打开完整 UTF-8 文本后直接进入编辑器，按文件名、扩展名或 shebang 自动识别语言并高亮，未知类型使用纯文本。支持中文、多行粘贴、方向键、Home/End、Delete/Backspace、Tab，Ctrl+Z 撤销、Ctrl+Y 或 Ctrl+Shift+Z 重做。Ctrl+S 或顶部「保存」显式写入文件；文件标题的 `*` 表示未保存修改。Esc 返回目录。

离开文件、关闭文件标签、切换项目或退出时，未保存修改显示保存、放弃和取消选项。外部内容或文件身份发生变化时拒绝保存，保留草稿。保存保留权限、换行符与末尾换行，采用同目录临时文件原子替换；它不能替代并发写入方之间的文件锁。

F5 后台读取磁盘版本并查看与编辑草稿的差异；普通保存失败也会尝试打开比较视图。差异以「- 编辑草稿」「+ 磁盘内容」显示变化区域，方向键、PageUp/PageDown 或滚轮浏览。Esc 或点击顶部第一行保留草稿；R 或点击第二行明确丢弃草稿并重新加载磁盘版本，随后留在编辑器检查。重新加载前再次验证文件身份和内容；如果磁盘再次变化，更新比较结果。读取失败、项目边界外的路径或不可编辑的磁盘版本不会替换草稿。此流程不会强制覆盖磁盘，也不提供自动合并。

F11 切换编辑器聚焦视图；宽度足够时旁边显示可展开的目录树，F6 在列表与代码之间切换焦点。目录树聚焦后使用上下键选择、左右键展开或收起及导航父子项、Enter 打开文件或切换目录展开状态，Esc 返回代码；点击代码也会恢复编辑焦点。滚轮作用于指针所在的列表或代码区域。普通及聚焦视图的文件标签溢出时，可点击 ‹ / › 切换文件。

Ctrl+F 查找、Ctrl+H 替换、Ctrl+G 跳转到行；查找中 Enter / Shift+Enter 定位下一处或上一处。替换中 Tab 切换查找与替换输入，替换输入中 Enter 替换当前匹配，Ctrl+Enter 替换全部。Shift 加方向键可选择文本，也可鼠标拖选；Home 在缩进起点与行首之间切换，Enter 延续当前缩进，选中文本后 Tab / Shift+Tab 调整缩进。

查找栏位于路径下方，替换输入单独占一行，不覆盖文件标签或代码；长输入显示末尾并保持输入光标可见。代码区标记所有匹配项，当前选区使用选中背景；底部显示匹配序号与操作提示，Esc 关闭输入栏。

设置中的「减少编辑器动画」或 `/settings reduce-motion=on` 可关闭编辑器聚焦切换动画，偏好重启后保留；使用 off 恢复动画。该选项目前只作用于编辑器聚焦动画。

## 输入中引用其他会话

主对话和右侧「侧聊」的消息输入都支持在词首输入 `@`，按会话标题、完整 ID 或项目路径即时筛选其他会话；不显示当前输入所属的会话。候选显示标题、项目路径和 ID，同名会话可用项目或 ID 区分；窄侧栏优先显示真实标题，项目与稳定 ID 用于进一步辨识。

`↑` / `↓` 移动选择，`Tab` 或 `Enter` 插入，鼠标单击候选也可插入。插入结果是稳定的 `@{ses_FULLID}` 加一个空格，不会直接发送消息。没有匹配时回车不会发送尚未完成的搜索。`Esc` 只关闭候选并保留草稿，再次编辑后可以重新搜索。也可直接键入或粘贴完整的 `@{ses_FULLID}`，完整 token 不会触发候选，正常发送时原样保留。

主输入与侧聊分别维护筛选和选择状态。斜杠命令输入不触发会话候选；文件编辑器、终端和各类弹窗中的 `@` 保持原本输入行为。发送时运行层读取来源会话的规范事件并附加最近用户、助手和工具记录快照，agent 可以直接阅读。每次最多引用 4 个会话，每个快照最多 8 KiB、总追加内容最多 24 KiB；超出时保留最近内容并标记截断。引用只展开一层，不递归读取来源里提到的其他会话。自引用、无效/不存在会话和不同用户所属会话会被拒绝；引用块明确标注为不可信资料，保持当前会话的权限与执行目标不变。

### 侧聊模型、权限与上下文控件

侧聊输入底部新增一行权限、上下文用量、供应商/模型入口，直接复用主对话现有的 PermissionDialog、ContextDialog 和 ProviderDialog，支持相同键盘、鼠标和最小化行为。弹窗边框标明「主对话」或「侧聊 · 实际标题」；打开时锁定目标会话 ID，不因输入焦点或主会话切换而误写其他会话。侧聊聚焦时 Shift+Tab 打开自己的权限选择器，Ctrl+G 返回后主控件仍保持主对话配置。

侧聊供应商/模型写入该侧会话的 session routing，权限只更新侧聊下一次运行的选项。运行中切换不会改写已经启动的 RunOptions；队列中的下一条使用新配置。旁路权限与主对话相同，必须先阅读风险提示并按 `y` 明确确认，Enter 不会启用。新侧聊创建时不写固定标题，由运行层自动命名；TUI 不覆盖已有用户自定义标题，旧默认标题的识别与修复由运行层处理。
