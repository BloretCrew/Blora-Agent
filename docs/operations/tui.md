# TUI 快捷键

| 键 | 作用 |
|---|---|
| Enter | 发送当前输入；以 `/` 开头则执行命令 |
| Backspace | 删除输入 |
| `[` / Left | 上一个会话 |
| `]` / Right | 下一个会话 |
| PageUp / PageDown | 滚动 transcript |
| Home / End | 滚到最早 / 最新 |
| y / n | 批准或拒绝当前审批（输入为空时） |
| Ctrl+N | 新建会话 |
| Ctrl+C / Esc | 请求取消并退出 |

## 斜杠命令

`/help` `/new` `/compact` `/tasks` `/yes` `/model` `/cancel` `/fork` `/resume` `/export` `/permissions` `/mode` `/search [query]` `/tools` `/copy`
