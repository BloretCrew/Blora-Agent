# @bloret-crew/blora-agent

Blora Agent CLI installer for Linux, macOS, and Windows.

## Install

```bash
npm install -g @bloret-crew/blora-agent@beta
blora --help
```

The package downloads the matching executable from the GitHub release for the package version. Set `BLORA_SKIP_BINARY_DOWNLOAD=1` when creating a package archive without downloading a binary.

Blora Agent is a local-first Code, Work, and Agent harness. See the [main repository](https://github.com/BloretCrew/Blora-Agent) for configuration, providers, security, and usage.
